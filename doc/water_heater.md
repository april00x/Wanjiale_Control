# 万家乐燃气热水器 · 实体清单

[Wanjiale Control](../README.md) 在燃气热水器上会创建的全部实体，配置仪表盘和自动化时对照用。

关于实体 ID：集成启用了 `has_entity_name`，实体 ID 由设备名和实体名拼成。设备名叫「热水器」的话，主实体是 `water_heater.热水器`，增压开关是 `switch.热水器_增压`。实际 ID 在「开发者工具 → 状态」里看。

关于创建规则：不是所有实体都会建出来。集成按机型能力表和设备实际上报的数据决定建哪些，没探测到的功能就没有实体。带「诊断」标记的实体在界面里归到设备的诊断分类下，默认折叠，主要用来排障，不建议拿去做自动化。

## 主实体

| 实体名称 | 平台 | 说明 |
| --- | --- | --- |
| 设备名 | `water_heater` | 开关机、设定温度、模式切换 |

温度上限随模式变化：ECO 48 ℃，随温感按环境修正量推算，其余模式 30~60 ℃。模式列表取自机型模板和实机上报，可能包括舒适浴、随温感、儿童浴、老人浴、ECO、SUR、厨房洗。

## 关于创建依据

控制类实体由功能开关决定，集成判断某个功能可用之后才建对应的实体。判断依据是机型能力表加上设备实际上报过的数据，选项页可以强制开启或关闭某个功能，用来处理两者都定不下来的机型。

只读类实体则看设备是否上报过对应的数据，上报过就建。部分机型有各自的基线数据列表，用来避免设备上线、离线时实体列表来回波动。
