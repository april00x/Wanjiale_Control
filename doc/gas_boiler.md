# 万家乐燃气壁挂炉 · 实体清单

[Wanjiale Control](../README.md) 目前还没有适配燃气壁挂炉（产品码 002）。设备会出现在 Home Assistant 里，但只能看，不能控制。

## 

### 设备卡片

| 字段 | 来源 |
| --- | --- |
| 名称 | 云平台里的设备名 |
| 制造商 | 万家乐 (Wanjiale) |
| 型号 | 设备上报的型号，没上报时显示「通用设备」 |
| 固件版本 | 设备上报的版本号 |
| 序列号 | 设备 did |

### 实体

只创建一个实体，归在诊断分类下，默认折叠：

| 实体名称 | 平台 | 说明 |
| --- | --- | --- |
| 原始状态(未收录品类) | `sensor` | 状态值是设备已上报的点位数量。属性里有设备标识、云平台产品码、机型、说明和原始点位（`dvid: 值`） |



## 适配进度

壁挂炉一台设备同时有卫浴和供暖两套温度，代码里的角色机制已经为这两路预留，但还没接入，找用万家乐的用户太难了。
